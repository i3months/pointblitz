# 0010 서버 영상 경로: NVENC + WebSocket + WebCodecs 먼저

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 소유자

## 맥락
서버가 그려 영상으로 보내는 경로가 필요하다. wgpu 에는 영상 인코더가 없다. V100·RTX 4070 모두 NVENC 를 가진다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| **WebSocket + WebCodecs(H.264)** | 구현 단순, 브라우저에서 프레임 단위 디코드 제어 | TCP 라 손실 시 지연 증가 |
| WebRTC | 지연 최소, 혼잡 제어 | 구현·시그널링 복잡 |
| HLS/DASH | 표준 | 지연이 초 단위 |

## 결정
NVENC H.264 로 인코딩하고 WebSocket 으로 보내 브라우저 WebCodecs 로 디코드한다. 입력은 같은 WebSocket 으로 역방향 전송한다.
WebRTC 는 P3 이후 지연 비교용으로 추가한다.

## 대가
- 렌더 결과를 GPU → 인코더로 넘기는 경로(가능하면 GPU 메모리 공유, 안 되면 복사)를 구현해야 한다. 복사 비용은 지표로 기록한다.

## 다시 볼 조건
- 입력 → 화면 지연이 측정상 문제가 되면 WebRTC 를 기본으로 바꾼다.
