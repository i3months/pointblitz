# 0003 렌더 코어 하나, 실행 위치 셋

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 소유자

## 맥락
"브라우저에서 그리기 / 네이티브에서 그리기 / 서버가 그려 영상으로 보내기" 중 무엇이 나은지는 만들어서 재 봐야 안다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| **코어 하나 + 실행 위치 셋** | 같은 그리기 코드로 세 방식을 공정하게 비교, 유지보수 한 곳 | 코어가 창·네트워크에서 완전히 분리돼야 함 |
| 브라우저만 | 단순 | 다른 방식과 비교 불가 |
| 서버 영상만 | 클라이언트 3D 코드 0 | 지연·서버 비용을 비교할 기준이 없음 |

## 결정
`pointblitz-core` 는 창·네트워크·브라우저 API 에 의존하지 않는다. 실행 위치는 얇은 크레이트(`native`, `web`, `server`)로 둔다.

## 대가
- 입력 이벤트·프레임 루프·자원 수명 관리를 실행 위치마다 따로 구현한다.

## 다시 볼 조건
- 한 실행 위치가 코어에 특수 경로를 계속 요구하면 경계를 다시 나눈다.
