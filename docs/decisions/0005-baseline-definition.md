# 0005 비교 기준(기존 방식)의 정의

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 소유자

## 맥락
skylens 는 skyrecon 점군을 아직 그리지 않는다(현황판은 3DGS). "기존 방식" 을 같은 데이터로 재려면 기준을 정의해야 한다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| **skylens 의 three.js 사용 방식을 같은 점군에 적용** | skylens 에 붙였을 때의 모습과 같음, 누구나 재현 가능 | skylens 실제 코드 그대로는 아님 |
| 최적화한 three.js(워커 파싱·증분 갱신) | 더 강한 기준 | "기존 방식" 이 아님 |
| 기존 3DGS 현황판 | 실제 코드 | 데이터가 달라 비교 불가 |

## 결정
three.js 0.185(skylens 와 같은 버전) + `PLYLoader` + `THREE.Points` + `PointsMaterial`.
이벤트마다 PLY 전체를 HTTP 로 받고, 메인 스레드에서 해석하고, 기존 `Points` 를 버리고 새로 만든다.
점 크기·모양·색·해상도는 SPEC §3.2 와 같게 맞춘다.

## 대가
- 최적화한 three.js 와의 비교는 별도 열로만 추가한다(공정성 보강용, P4 에서 검토).

## 다시 볼 조건
- skylens 가 실제로 점군 표시 코드를 넣으면 그 코드를 기준으로 바꾼다.
