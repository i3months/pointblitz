# 0007 점 모양·크기·색

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 소유자

## 맥락
공정한 비교를 위해 기준 방식과 새 방식이 같은 화면을 그려야 한다.

## 선택지
| 항목 | 선택지 | 고른 것 | 이유 |
|---|---|---|---|
| 모양 | 사각형(three.js 기본) / 원 | 원 | 점군 뷰어의 일반적 표현, 방향에 따른 모양 차이 없음. 기준 방식도 원으로 맞춘다(P0.4) |
| 크기 | 화면 고정 px / 거리 비례 | 화면 고정 2 px | 거리 비례는 구현마다 공식이 달라 같은 화면을 보장하기 어렵다 |
| 색 | 조명 적용 / PLY 색 그대로 | PLY 색 그대로 | 비교 대상은 그리기 속도다. 조명은 셰이더 비용을 섞는다 |
| 해상도 | 1280×720 / 1920×1080 / 4K | 1920×1080, DPR 1 | 흔한 관제 모니터 해상도. 다른 해상도는 비용 모델(픽셀 수)로 추정 |

## 결정
- 모양: 원. 크기: 화면 기준 고정 픽셀 지름, 기본 2 px(거리에 따라 커지지 않음 — three.js `sizeAttenuation: false` 와 같음).
- 색: PLY 의 sRGB 8 bit 그대로, 조명 없음.
- 측정 해상도: 1920×1080, 장치 픽셀 비 1.

## 대가
- 가까이 가면 점 사이가 비어 보인다. 거리 기반 크기는 옵션으로 두고 비교표 기본값은 고정 크기로 한다.

## 다시 볼 조건
- 소유자가 보기 품질 기준을 따로 정하면 바꾼다.
