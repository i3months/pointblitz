# 0024 렌더 코어 설계 (P1.2)

- 상태: 제안
- 날짜: 2026-10-07
- 결정한 사람: 작업자(제안) → 감독 검토

## 맥락
`pointblitz-core` 가 청크(결정 0022)를 받아 GPU 에 올리고 그린다. 결정 0006(불투명·정렬 없음), 0007(원형 2 px), 0009(세대 교체),
0013(좌표·reversed-Z)을 코드로 옮기며 생긴 선택을 적는다.

## 선택지와 결정

## 결과 (이 PC — `cargo test -p pointblitz-core --test render -- --nocapture`)
어댑터 `NVIDIA GeForce RTX 4070 (Vulkan)` 에서 4 개 GPU 시험 통과:
- 점 하나가 CPU 투영이 가리키는 픽셀에 그 색으로 찍히고, 배경은 검정, 켜진 픽셀은 1~4 개(2 px).
- 먼 점·가까운 점을 두 순서로 넣어도 가까운 점이 보인다(정렬 없이 깊이로).
- 세대: 같은 세대 추가 → 보임, 새 세대 첫 청크 → 보류(이전 세대 계속 보임), `LAST` 청크 → 교체·이전 해제, 오래된 세대 → 버림.
- ENU 원점에서 5 km 떨어진 점을 3 m 앞에서 보아도 CPU 투영 픽셀에 찍힌다.

GPU 가 없는 CI 에서는 시험이 "skipped" 를 출력하고 통과한다.

## 대가
