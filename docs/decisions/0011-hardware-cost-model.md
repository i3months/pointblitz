# 0011 비교표는 하드웨어 비용 모델과 함께

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 소유자

## 맥락
측정 장비는 V100 16 GB, RTX 4070 두 대뿐이다. 비교표가 이 두 장비에 묶이면 안 된다("이 정도 하드웨어면 이 정도 성능").

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| 측정 장비 두 대의 수치만 공개 | 단순, 실측 그대로 | 다른 하드웨어에서의 성능을 말할 수 없다 |
| **단계별 비용 모델 + 두 장비로 계수 맞춤** | 사양만 넣으면 다른 하드웨어 추정, 어느 단계가 병목인지 보인다 | 모델 오차 |
| 공개 벤치마크 점수(예: 3DMark)로 비례 환산 | 쉬움 | 단계별 병목이 다르면 크게 틀린다 |

## 결정
단계마다 하드웨어 독립 양(바이트, 점 수, 그려진 픽셀, 청크 수, 해상도×fps)과 그것을 좌우하는 하드웨어 값
(네트워크·PCIe·메모리 대역폭, CPU 단일 스레드 처리량, GPU 정점 처리량·필레이트, 인코더 처리량)을 짝지어 기록한다.
두 장비에서 계수를 맞추고, 다른 GPU 는 공개 사양으로 추정하되 추정값이라고 표시한다.

## 대가
- 단순 선형 모델이라 캐시·드라이버 효과는 오차로 남는다. 한 장비로 맞춘 계수로 다른 장비를 예측한 오차를 함께 공개한다.

## 다시 볼 조건
- 예측 오차가 크면 단계를 더 쪼개거나 모델을 바꾼다.
