# 0015 라이선스: MIT OR Apache-2.0

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 소유자

## 맥락
오픈소스로 공개하고 널리 쓰이게 하는 것이 목표다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| **MIT OR Apache-2.0** | Rust 생태계 표준, 특허 조항(Apache)과 단순함(MIT)을 사용자가 고름 | 파일 두 개 |
| MIT | 가장 단순 | 특허 조항 없음 |
| Apache-2.0 | 특허 조항 | GPLv2 와 비호환 |
| GPL 계열 | 파생물 공개 강제 | 채택 장벽, 상업 사용자 이탈 |

## 결정
MIT OR Apache-2.0 이중 라이선스. Rust 생태계(wgpu 포함)와 skyrecon 이 같은 방식을 쓴다.
의존성은 이와 호환되는 것만 쓴다(GPL·AGPL 금지).

## 대가
- 기여자는 두 라이선스로 동시에 내는 것에 동의해야 한다(기여 안내에 적는다).
