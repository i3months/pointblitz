# 0012 문서는 한 리포에, 감독은 같은 PC 의 별도 세션

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 소유자

## 맥락
이전 시도(skylens-renderer + skylens-renderer-lab)의 문제:
- 제품·연구 리포가 나뉘어 기록이 흩어졌다.
- 감독이 PR 마다 중간·낮음 피드백을 만들어 정리 작업이 끝없이 반복됐다.
- 사용자 의도와 다른 기준(대역폭 상한)이 SPEC 에 들어갔는데 걸러지지 않았다.
- 감독이 GPU 없는 클라우드에서 돌아 측정을 재현하지 못했다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| **한 공개 리포 + 로컬 감독 세션** | 결정 기록이 오픈소스 독자에게 보임, 감독이 GPU 로 측정 재현 | PC 가 켜져 있어야 함 |
| 별도 비공개 lab 리포 | 내부 기록 분리 | 기록이 흩어짐, 공개 가치 손실 |
| 클라우드 루틴 감독 | 상시 동작 | GPU 없음 |

## 결정
모든 문서·결정 기록은 pointblitz 리포에 둔다. 감독은 같은 PC 의 별도 자동 작업 세션이 PROJECT.md §3 체크리스트로 한다.
반려는 치명·높음만, SPEC 변경은 소유자만.
