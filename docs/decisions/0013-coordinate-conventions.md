# 0013 좌표 규약

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 작업자 제안 → 감독 동의(PR #1 검토) → 소유자 승인(2026-10-07)

## 맥락
skyrecon 은 ENU(z 위), 카메라 OpenCV 규약(x 오른쪽·y 아래·z 앞)을 쓴다. wgpu 관례는 뷰 공간 y 위·−z 앞, 클립 깊이 0..1.
이전 리포의 규약(픽셀 중심 i+0.5, OpenCV → GL `diag(1,−1,−1)`)은 검증돼 있다.

## 결정
- 월드: ENU 그대로(x 동, y 북, z 위), 1 unit = 1 m. 데이터를 다른 축으로 바꿔 저장하지 않는다.
- 카메라: 뷰 행렬에서 ENU → 뷰 공간(오른쪽 x, 위 y, 앞 −z)으로 바꾼다. 위 방향 기본값은 +z.
- 투영: wgpu 클립 깊이 0..1, 정밀도를 위해 reversed-Z(가까운 쪽 1).
- 원점에서 먼 좌표(수 km)는 청크마다 지역 원점을 두고 f32 오차를 막는다.
- 변환은 `pointblitz-core` 의 카메라 모듈 한 곳에서만 한다.

## 대가
- reversed-Z 는 three.js 기준(일반 Z)과 깊이 정밀도가 달라 SSIM 에 작은 차이가 날 수 있다. P1.3 에서 원인을 구분해 기록한다(PR #1 감독 의견).
- three.js(y 위) 기준 방식과 시점을 맞출 때 변환이 한 번 필요하다. 시점 파일은 ENU 로 저장하고 각 구현이 변환한다.
