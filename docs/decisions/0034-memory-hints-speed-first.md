# 0034 wgpu 메모리 할당 설정은 속도로 고른다 (0027 의 "메모리 우선 할당" 항목 대체)

- 상태: 제안
- 날짜: 2026-10-08
- 결정한 사람: 작업자(제안) → 감독 검토
- 대체: 결정 0027 표 2 번(`MemoryHints::MemoryUsage` — 메모리를 줄이려고 고름)
- 관련: SPEC §7.1·INTENT 원칙 2(2026-10-08 소유자: 메모리는 제약이 아니다), PR #20 검토 5

## 원칙
**메모리를 줄이려고 속도·지연을 내주는 선택은 하지 않는다.** 메모리는 기록만 한다(소유자 결정). 설정 사이에 속도 차이가 있으면 빠른 쪽을 쓴다. 차이가 없을 때만 다른 기준(바꾸지 않음)으로 정한다.

## 측정 (같은 세션, 번갈아, 2026-10-08 02:36~)
`--memory-hints`(native)·`?memory=`(web, WebGPU 기본 모듈)로 `memory`(`MemoryUsage`)와 `performance`(wgpu 기본)를 번갈아 잼. replay ×60 3 회씩, orbit 2 회씩.

| 지표 | native `memory` | native `performance` | web `memory` | web `performance` |
|---|---:|---:|---:|---:|
| preview p50 (×60) | 18.3 (17.6–26.1) | 21.6 (20.0–26.2) | 25.8 (24.4–26.8) | 27.4 (26.0–27.6) |
| refined p50 (×60) | 146.6 (145.5–152.3) | 155.8 (141.1–156.5) | 121.6 (104.0–123.8) | 125.8 (110.2–137.3) |
| frame p50 / p95 / p99 (orbit) | 1.58 / 1.80 / 1.98 | 1.54 / 1.83 / 2.00 | 5.65 / 7.15 / 7.70 | 5.45 / 7.05 / 7.52 |
| `mem_cpu` (×60, 기록) | 362.0 MB | 403.2 MB | 191.6 MB | 176.3 MB |

차이는 모두 실행 간 범위 안이고 방향도 지표마다 엇갈린다(지연은 `memory` 가, 프레임은 `performance` 가 조금씩 작다). **속도로는 어느 쪽도 낫지 않다.**

## 결정
`MemoryHints::MemoryUsage` 를 그대로 둔다. 이유는 메모리가 아니라 "속도 차이가 없을 때는 바꾸지 않는다" 다(측정한 값과 판정의 연속성).
- native `--memory-hints performance`, web `?memory=performance` 로 언제든 다시 비교할 수 있다.
- 다른 장비·더 큰 데이터에서 `performance` 가 빠르면 그쪽으로 바꾼다.

## 다시 볼 조건
- 다른 GPU·드라이버(V100 등, P4 비용 모델)에서 같은 A/B 를 해서 차이가 범위를 벗어날 때.
