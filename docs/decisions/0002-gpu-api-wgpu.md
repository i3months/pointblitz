# 0002 GPU 추상화: wgpu

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 소유자

## 맥락
같은 파이프라인을 Vulkan·Metal·DX12·OpenGL·WebGPU 에서 같은 단계로 돌려야 한다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| **wgpu** | 한 API 로 Vulkan/Metal/DX12/GL(ES)/WebGPU, 헤드리스 렌더 가능, WGSL 셰이더 하나 | WebGPU 미지원 브라우저는 WebGL2 경로로 기능 제한(컴퓨트 셰이더 없음) |
| Vulkan 직접(ash) | 최대 제어 | 브라우저 불가, 플랫폼마다 따로 |
| bgfx / Dawn(C++) | 성숙 | Rust 와 경계, 웹 빌드 복잡 |
| three.js 유지 | 생태계 | 바꾸려는 대상 그 자체 |

## 결정
wgpu 를 쓴다. 셰이더는 WGSL 하나로 쓰고, WebGL2 대체 경로에서도 돌도록 **기본 경로는 컴퓨트 셰이더 없이** 만든다.
컴퓨트가 필요한 최적화(GPU 컬링 등)는 기능 플래그로 붙이고, 없을 때의 대체 경로를 함께 둔다.

## 대가
- WebGL2 경로에서는 GPU 컬링·간접 그리기 같은 최적화를 못 쓴다. 비교표에 WebGPU / WebGL2 를 따로 적는다.

## 다시 볼 조건
- 특정 백엔드에서 wgpu 오버헤드가 측정상 병목이면 그 백엔드만 따로 검토한다.
