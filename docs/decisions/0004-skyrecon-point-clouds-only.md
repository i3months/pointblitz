# 0004 입력은 skyrecon 점군만

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 소유자

## 맥락
SkyLens 현황판은 지금 3D 가우시안 스플랫(56 B/스플랫)을 그리지만, 프로젝트에서 3DGS 가 빠졌다.
복원은 skyrecon(Rust)이 맡고 출력은 법선·색이 붙은 점군 PLY(27 B/점)다. 텍스처 표면은 다른 팀원이 진행 중이다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| **skyrecon 점군만** | 실제 파이프라인과 일치, 정렬이 필요 없는 단순한 그리기 | 3DGS 사용자는 대상 밖 |
| 3DGS 만 | 기존 현황판과 같음 | 프로젝트에서 빠짐 |
| 둘 다 | 범위 넓음 | 지금 필요 없는 복잡도 |

## 결정
skyrecon 점군만 다룬다. 메시(텍스처 표면·지형·건물)는 코어 설계에서 자리만 남기고 P5 에서 다룬다.

## 다시 볼 조건
- SkyLens 가 3DGS 를 다시 쓰기로 하거나, 텍스처 메시가 나오면 SPEC 을 갱신한다.
