# 0006 불투명 점 + 깊이 테스트, 정렬 없음

- 상태: 승인
- 날짜: 2026-10-07
- 결정한 사람: 작업자 제안 → 감독 동의(PR #1 검토) → 소유자 승인(2026-10-07)

## 맥락
3DGS 는 반투명이라 매 프레임 깊이 정렬이 필요하다(기존 현황판은 69만 개를 워커에서 CPU 정렬).
skyrecon 점은 불투명한 표면 표본이다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| **불투명 + 깊이 테스트** | 정렬 0, 프레임 비용이 점 수에 선형, three.js `Points` 와 같은 화면 | 가장자리 앨리어싱 |
| 반투명 블렌딩 + 정렬 | 부드러운 가장자리 | 정렬 비용, 기준 방식과 다른 화면 |
| 표면 재구성·후처리(EDL 등) | 보기 좋음 | 지금 범위 밖, 비교 왜곡 |

## 결정
불투명 점을 깊이 테스트로 그리고 정렬하지 않는다. 화질 보강(EDL 등)은 기준과 비교가 끝난 뒤 옵션으로 검토한다.

## 대가
- 원형 점은 프래그먼트에서 `discard` 로 자른다. 초기 깊이 테스트 이점이 줄 수 있어 측정으로 확인한다.

## 다시 볼 조건
- `discard` 비용이 측정상 크면 사각형 점이나 다른 방식을 검토한다.
