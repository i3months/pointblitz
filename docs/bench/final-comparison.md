## 6. 요약(소유자 보고서용)
- **as-is(SkyLens 식 three.js) 대비 to-be(PointBlitz 0.2.0)**: 새 정밀 스냅샷의 첫 반영 web 3.38 배(138 → 40.8 ms), webgl 2.56 배, native 4.89 배, video 2.99 배; 완전 반영 web 1.42 배, webgl 1.33 배, native 1.26 배, video 2.99 배; cold 첫 반영 web 7.96 배. 미리보기는 web 1.42 배·native 2.50 배·video 1.74 배, webgl 은 차이 없음. 받는 데이터 304 → 135 MB(서버 영상 10.1 MB), 렌더러 메모리 355 → 204 MB(web).
- **같은 데이터의 three.js 대비(Rust·wgpu·wasm 의 몫)**: WebGPU 에서는 PointBlitz 가 그리기 1.5 배·첫 반영 1.3 배 빠르고 메모리 1.25 배 적다. WebGL2 에서는 three.js 가 그리기 약 2 배 빠르다.
- **그리기 속도는 as-is 와 같은 수준이다**: batch 30 프레임당 as-is B2 1.39 ms(f32 좌표, WebGL2) 대 web 1.42, native 1.37 ms(webgl 3.86 ms 는 느림). 이득은 그리기가 아니라 새 데이터가 화면에 나오기까지의 경로에서 온다.
- 목표(web·video 정밀 첫 반영 ≤ 50 ms): 통과(40.8 · 46.2 ms).
