# P4.6 공개표 측정 계획 — C1–C4 같은 세션 전체 비교 (측정 전 고정)

- 날짜: 2026-10-08. 감독 요청(PR #42 병합 뒤 메시지)에 따른 계획. 바꾸려면 측정 전에 이 문서를 고친다.

## 순서
1. **C(서버 틱 위상 맞추기, PR #41 감독 결정)를 먼저 끝낸다**: 결정 기록 → 구현·단위 시험 → C1–C4 A/B → 수용 기준 판정. 기본값이 바뀌는지가 정해진다.
2. 그다음 전체 비교 한 번. server video 는 **그때의 기본값**으로 판정 행을 만들고, 기본값이 C 로 바뀌었다면 끔(immediate, 바뀌기 전 기본) 값을 "고치기 전" 행으로 함께 싣는다 — 한 세션에서 둘 다 잰다(video 대상 둘: `video`, `video-nolock`).
   이 순서가 공개표에 덜 헷갈린다(감독 의견과 같음).

## 대상·시나리오·회수
- 대상: three.js(기준 방식, 밉맵 끔), native, web(WebGPU 기본 모듈), webs(WebGPU 전용 모듈), webgl(WebGL2), video(server video 기본) [+ video-nolock, 위 2 의 경우].
- 시나리오: cold 5 회, orbit 5 회, replay ×60 3 회. 대상끼리 실행마다 번갈아(`bench/suite.sh`).
- 모든 실행은 `bench/gpu-watch.mjs`(→ `bench/measure-env.ps1`: 화면 켜 둠, 측정 프로세스 전원 조절 끔, CPU 보정·성능 기록).

## 유효성과 실행 처리
| 규칙 | 기준 | 언제 |
|---|---|---|
| C1 | 실행 전 2 s GPU 사용률 평균 > 15 % → 무효 | 실행마다(`bench/valid.mjs`) |
| C2 | server video 렌더·인코딩 p50 > 같은 시나리오 video 실행 중앙값 × 2 → 무효 | 세션 끝(`bench/contamination.mjs --apply`) |
| C3 | 화면 시계 `display_hz` 59.5–60.5 Hz 밖 → 무효. browser = rAF 4 구간, native = 끝의 vsync present 시계 | 실행마다 |
| C4 | CPU 보정 < 기준(12,650 회/s)의 90 % 또는 기록 없음, server video 늦은 틱 > 1 % → 무효 | 실행마다 |
| 전원 조절 확인 | 실행마다 `cpu.log` 의 "조절 끈 프로세스 수" > 0, 실패 0 — 대상별로 표에 적음 | 세션 끝 |

- 실패하거나 C1·C3·C4 로 무효인 실행은 **같은 조건으로 1 회만** 다시 돌린다. 첫 시도의 파일은 `<run>.try1-failed.*` / `<run>.try1-invalid.*` 로 남기고, 모든 시도를 `runs.log` 에 적는다. 두 번째도 무효면 그 실행은 빠진다(회수가 줄었다고 표에 적음).
- C2 로 무효인 실행은 `contaminated/` 로 옮겨 집계에서 빼고 목록을 보고에 싣는다(다시 돌리지 않음).
- 한 대상·시나리오의 유효 실행이 3 회 미만이면 그 칸은 판정하지 않고 "유효 실행 부족" 으로 둔다.

## 판정표 형식(`docs/bench/comparison.md`)
| 지표 | 대상 | 목표(SPEC §7.1) | 값(중앙값, 최소–최대, 유효 실행 수) | 판정 | C1–C4 | 이전 판정(단계, 조건) |
|---|---|---|---|---|---|---|

- 판정: 통과 / 미달 / 기록만 / 유효 실행 부족.
- 이전 판정: 예 "P3.4 통과(C4 미상)". 새 판정과 다르면 둘 다 보인다.
- frame_time 의 기준 방식 값은 SPEC §7.1 정정값(1.7 / 1.9 / 2.0 ms)이고, **같은 세션 three.js 값도 함께 싣는다**(세션 간 흔들림, P4.4).
- 지금까지 검토가 요구한 것: 점 영역 SSIM, 실행별 최대(빠짐은 1 % 초과 실행 수·최대), 요청 때 그리기 각주, native `first_frame` 기준점(PR #13), 공개 wasm 크기는 CI 빌드 값(PR #21), 판정 값(batch=1)과 진단 값(batch=30) 함께(PR #30).
