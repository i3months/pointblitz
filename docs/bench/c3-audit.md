# C3 감사 — 지난 측정의 화면 시계 (결정 0040)

- 날짜: 2026-10-08. 도구: `node bench/audit-c3.mjs <suite dir> ...` (target/bench, 로컬).
- 규칙 C3: 실행의 프레임 시계가 59.5–60.5 Hz 밖이면 무효. 디스플레이가 Windows 화면 끄기 시간(AC 300 s)으로 꺼지면 Chrome 의 프레임 시계가 약 56.6 Hz 로 떨어진다.
- 근거의 세기: **raw**(4 구간 — 도중 변화도 잡음) > **중앙값만**(`frame_interval_p50` — 실행 후반의 변화는 놓칠 수 있음).
- native(감독 결정): 그리기 루프 간격(`frame_interval`)으로는 보지 않는다. present 간격 기록이 없는 지난 native 실행은 **같은 세션 브라우저 실행의 시계로 추정**한다(같은 PC·같은 화면).
- 지난 숫자는 지우지 않는다. 범위 밖 실행이 판정에 쓰인 곳은 그 문서에 표시하고, 다시 잰 값을 별도 행으로 싣는다.
