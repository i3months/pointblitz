## 반려 사유 (높음)

### H1. C4 미상 진단 값을 조건 없이 공개 주장에 썼다 (#10)

- README: "in an earlier diagnostic session that synchronised every 30 frames, WebGPU drew a frame in 1.43 ms, like native (1.37 ms)".
- 이 값은 P4.1 진단(C4 미상, comparison.md 각주 1 에 "C4 미상" 명시)이다. 공개 주장은 C1~C4 측정으로만 한다는 원칙(SPEC §7.1, TASKS P4.6)과 맞지 않는다.
- 고칠 것 둘 중 하나:
  - (가) C1~C4 로 batch=30 진단을 다시 재서 그 값을 쓴다.
  - (나) 수치를 빼고 "동기화를 줄이면 native 와 비슷해지는 진단이 있었다(측정 유효성 규칙 이전, comparison.md 각주 1)" 로 쓴다.
