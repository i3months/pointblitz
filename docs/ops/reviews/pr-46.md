## 판단 — 서버 영상 프레임 빠짐의 판정 방식 (감독 결정)

- SPEC §7.1 은 여러 실행을 어떻게 묶어 판정하는지 적지 않는다. 이 프로젝트의 모든 지표는 P1.5 부터 **실행별 값의 중앙값**으로 판정해 왔다(P3.4 의 빠짐도 그랬다).
- 빠짐 하나만 "모든 실행 ≤ 1 %" 로 바꾸면 결과를 본 뒤 판정 방식을 바꾸는 것이 된다. 따라서 **중앙값 판정(통과)을 유지한다.**
- 대신 같은 칸과 요약에 "1 % 초과 2/5 회, 최대 6.32 %" 를 함께 싣는다(이미 그렇게 했다). 공개 문구(P4.7)에서도 이 분포를 빼지 않는다 — 체크리스트 #10.
- **감독 정정**: PR #38·#45 검토 노트의 "SPEC 빠짐 미달(쪽)" 표현은 이 중앙값 관례를 확인하지 않고 쓴 것이다. 실행 분포에 대한 관찰로 읽는다.
  - "모든 실행 ≤ 1 %" 는 0039·0042 의 **수용 기준**(기본값을 바꿀 때의 기준)이지 SPEC 판정 방식이 아니다.
