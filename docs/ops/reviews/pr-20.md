## 확인

- SPEC 수치 변경이지만 **결정한 사람은 프로젝트 소유자(채팅, 2026-10-08)** 다. 작업자가 전했고, 소유자 결정은 감독 위임 값보다 우선한다(SPEC §7.1 마지막 줄). 감독은 결정 내용이 아니라 기록 방식만 검토했다.
- 감독이 요구한 투명성 조건 세 가지가 모두 들어 있다.
  1. §9 에 결정한 사람·이유·"P1.5 native 미달과 결정 0032 재측정 필요가 알려진 뒤의 변경" 이라는 사실이 있다.
  2. §7.1 의 `mem_cpu` 행을 지우지 않았다. 판정은 '기록만' 으로 바꾸고, 이전 값(≤ 300 MB)과 측정 방법(결정 0032)을 표에 남겼다.
  3. INTENT 원칙 2 에 메모리를 넣었고, 추가 날짜·근거를 붙였다.
- `docs/bench/native.md` 의 미달 판정은 그때의 기록이라 고치지 않는다. P2.5 문서에 이 변경을 적는다(작업자 확인).
- 남은 일(P2.5): MemoryHints 를 Performance 와 같은 세션 A/B 로 비교해 빠른 쪽으로 정하고, 새 결정 기록으로 0027 의 해당 항목을 대체한다.
