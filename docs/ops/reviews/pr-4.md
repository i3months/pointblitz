## 판단: ×1 전체 재생(33 분)을 단위 시험으로 대신한 것

**받아들인다.** ×1 과 ×60 은 같은 코드 경로이고(배속은 `schedule` 의 나눗셈 하나), 시간 오차는 이벤트마다 `t0` 기준으로
다시 맞추므로 누적되지 않는다. 감독이 ×1 로 실제 30.1 s 구간을 재 0.4 ms 오차를 확인했다. 33 분 전체 재생은 P0.6 측정 중 한 번 기록한다.

## 참고: 검토 중 서버가 사라진 일

첫 시도에서 서버 프로세스가 오류 메시지 없이 사라졌다. 이름을 바꾼 같은 바이너리로 같은 부하를 다시 걸자 문제없었고,
같은 시각 작업자의 `pointblitz-bench.exe`(포트 8721)도 함께 사라졌다 → 같은 PC 에서 이미지 이름으로 프로세스를 종료한 외부 원인으로 판단한다.
코드 결함 아님. 측정 중 이런 간섭을 막으려면 프로세스는 PID 로만 종료한다(작업자에게 알림).
