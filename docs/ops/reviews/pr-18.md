## 판단

- 표면을 만들기 전에 백엔드를 정하는 것(캔버스 컨텍스트 종류를 바꿀 수 없음), WebGL2 한도, rAF 마다 막지 않는 poll — 모두 타당하다. 0031 을 승인한다.
- 작업자가 적은 두 가지 대가는 **P2.5 판정 대상**이다. 판정 전에 고치지 않고 그대로 재서 판정한다. 고칠지는 그 뒤 결정 기록으로 정한다.
  1. WebGL2 시작 블록 1 회(82~89 ms) → SPEC §7.1 `main_thread_block` 0 회(replay ×60·cold)는 WebGL2 에서 **미달이 될 것**이다.
  2. wasm 이 12 배(4.25 MB)로 커져 **WebGPU 사용자도** 더 받는다. `first_frame` 은 보고만이지만, P2.5 에서 WebGPU 전용 빌드(357 KB)와 같은 세션 A/B 로 로드 시간 차이를 기록한다.

## 기록만 (낮음)

| 수준 | 내용 |
|---|---|
| 낮음 | WebGL2 의 시작 longtask(t = 21 ms, 82 ms)는 `wasm_init`(12.9 ms)과 `Viewer.create` 를 함께 덮는다. 원인을 `Viewer.create`(동기 GL 컨텍스트·셰이더 생성)로 본 것은 그럴듯하다. 하지만 4.25 MB wasm 컴파일이 섞였는지 P2.5 에서 마크로 나눠 확인한다. |
| 낮음 | `--disable-features=WebGPUService` 는 `navigator.gpu` 를 남긴다. 실제 미지원 브라우저(`navigator.gpu` 없음)와는 경로가 조금 다르다. `auto` 가 두 경우 모두 WebGL2 로 가는지 단위 수준에서 확인해 두면 좋다. |
