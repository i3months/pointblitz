## 코드 검토
- `scatter.wgsl`: 팩을 `array<u32>` 로 읽는다(레코드 20 B·4 B 는 4 바이트 정렬). 2-D 작업 그룹 번호 `g.x + g.y·n.x·64` 가 전역 번호와 맞다. 창 밖 슬롯은 건너뛴다. add·move 는 x y z 와 rgb + 보임 비트, remove 는 보임 비트만 지운다. 패스 안 디스패치 순서가 add → move → remove 라 CPU 거울 (a) 와 같은 바이트가 된다.
- 한도: 팩은 레코드 경계에서 `max_storage_buffer_binding_size` 에 맞게 나누고, 그보다 큰 슬롯 버퍼는 창으로 묶는다. 늘리기(GPU 복사)는 흩뿌리기 전에 제출한다.
- 기본값은 `Mirror`(a). 계산 셰이더·스토리지 버퍼가 없는 장치(WebGL2)는 `Scatter` 를 요청해도 `Mirror`. 기존 경로·0.2.1 API 영향 없음.
- 결정과 다른 점(0052 메모): scatter 의 `bounds()` 는 마지막 비우기 뒤 쓴 모든 위치의 상자(보이는 칸보다 클 수 있음), 한 메시지 한 구역 안 같은 id 중복은 어느 쓰기가 이길지 정해지지 않음(생산자는 보내지 않음).
