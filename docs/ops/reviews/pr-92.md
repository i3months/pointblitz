## 확인한 것

- 원본 대조: SkyLens develop(`faaa855`) `third_party/pointblitz` 를 v0.2.0 태그와 비교했다. 줄바꿈·공백을 무시하면 `pointblitz-io`·`pointblitz` 는 완전히 같고, 다른 것은 `pointblitz-core` 의 `lib.rs`·`headless.rs`·`renderer.rs`·`points.wgsl` 와 새 파일(`layers.rs`, `layers/math.rs`, `mesh.wgsl`, `lines.wgsl`, `color.wgsl`, `tests/layers.rs`)뿐이다. 이 PR 은 그 파일들을 그대로 옮겼다(LF).
- 그 위의 변경은 rustfmt 와 `layers/math.rs` clippy 5 건(`chunks_exact(3)` → `as_chunks::<3>`, 인덱스 반복 → 반복자, 수동 카운터 → `enumerate`)뿐이고 동작은 같다.
- 공개 API: 0.2.0 의 공개 항목은 그대로 있고 더해지기만 했다(`layers` 모듈, `PointSize`, `Renderer::{set_point_size, prepare, draw}`, `Headless::capture_with`). 의존성은 0.2.0 과 같다(bytemuck, glam, pointblitz-io, wgpu 30.0.1). 청크 형식 v2 그대로 → 0.2.1.
- `scripts/check.sh` 각 단계 로컬 통과: fmt, clippy(host, x86_64-unknown-linux-gnu, wasm32 두 가지), 크레이트 경계, `cargo test --workspace`(새 `tests/layers.rs` 포함), publish dry-run 여섯 크레이트, node 시험 7 건.
- 소유자 승인: 소유자가 "0.2.1 배포는 확인 없이 바로 해도 돼요"(2026-10-16)라고 했다. 병합 뒤 태그 `v0.2.1` → release.yml(결정 0047).
