## 기록만 (중간·낮음)

| 수준 | 내용 |
|---|---|
| 중간 | `Encoder::new` 가 중간에 실패하면 이미 만든 CUDA 컨텍스트·인코더 세션을 풀지 않는다(드롭 가드 없음). 서버가 재시도하는 구조가 되면 새는 자원이 쌓인다. P3.2 에서 단계별 정리 가드를 둔다. |
| 중간 | `encode` 는 `lock.pitch >= width × 4` 를 가정하고 복사한다. 드라이버가 더 작은 pitch 를 주면 버퍼 밖에 쓴다. 한 줄 검사(`pitch < w*4` 면 오류)를 넣는다 — `unsafe` 구간의 전제는 코드로 확인하는 것이 원칙이다. |
| 낮음 | 인코딩 p99 가 감독 실행에서 3.3~4.5 ms 로 PR(2.96 ms)보다 높다. 한 프레임(16.7 ms) 안이라 문제는 없다. P3.4 에서 같은 세션 반복으로 잰다. |
| 낮음 | "픽셀이 다른 비율" 12~19 %(close_dense 91 %) — P3.4·P4 에서 마스크 SSIM 을 함께 싣는다(PR 이 이미 예고). |
