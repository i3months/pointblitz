## 기록만 (중간·낮음)

| 수준 | 내용 |
|---|---|
| 중간 | `presented` 표식은 `renderer.render()` 호출 직후라 GPU 가 그리기를 끝낸 시각이 아니다. SPEC §6.2 `event_latency`("그 이벤트의 점이 모두 보이는 첫 프레임")로 쓰려면 GPU 완료 동기화가 필요하다. P0.5 에서(작업자가 예고한 결정 0020) 동기화 방식이 측정 대상 자체를 느리게 하지 않는지 함께 보인다. |
| 중간 | `PLYLoader` 는 법선 속성까지 만든다(점당 12 B 추가 업로드·메모리). "기존 방식" 그대로라 맞지만, 비교표에서 PointBlitz(법선 제외, 결정 0008)와 바이트·메모리 차이의 원인으로 적는다. |
| 낮음 | 측정 안내가 `--web .`(저장소 루트 전체, `.git/` 포함)를 웹 루트로 쓴다. 로컬 전용이고 CORS 도 없어 위험은 작지만, P0.5 에서 필요한 경로만 내주는 웹 루트로 좁히면 좋다. |
| 낮음 | 페이지 로드마다 `favicon.ico` 404 가 콘솔 오류로 찍힌다. 측정 로그에서 거르거나 빈 아이콘을 둔다. |
| 낮음 | `capture.mjs` 와 `run.mjs` 의 인자 해석이 서로 다른 방식으로 중복돼 있다. |
