## 기록만 (중간·낮음)

| 수준 | 내용 |
|---|---|
| 중간 | `insert` 가 청크마다 JS → wasm 메모리 복사(최대 4 MB)를 한다. 그리고 `still` 시나리오는 응답 전체를 `arrayBuffer()` 로 받은 뒤 넣는다. P2.3(스트림으로 청크 단위 넣기)에서 메인 스레드 시간이 50 ms 를 넘지 않는지 청크별로 확인한다 — `main_thread_block 0` 목표와 직결된다. |
| 낮음 | `pb.gpu` 를 얻으려고 `navigator.gpu.requestAdapter` 를 한 번 더 부른다. 측정(P2.5) 때 첫 화면 시간에 섞이지 않게 마크 뒤로 빼거나 시간을 따로 기록한다. |
| 낮음 | `splitChunks` 는 헤더의 점 수만 믿고 자른다. 검증은 Rust `insert`(decode_header)가 하므로 안전하지만, 잘린 응답이면 마지막 조각이 짧은 채 넘어가 오류가 된다 — P2.3 의 스트림 처리에서 경계·끝(`LAST`) 처리를 시험으로 고정한다. |
