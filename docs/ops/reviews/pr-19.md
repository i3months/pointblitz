## 판단

- **승인.** 커널이 기록하는 최대값이라 표본 간격과 무관하고, 자가 점검 두 개(유지·짧은 스파이크)로 검증했다. 0020 은 본문을 고치지 않고 대체 표시만 붙였다(PROJECT §4).
- 지난 문서(P0.6·P1.5)의 수치는 그때의 방법으로 잰 기록으로 두고, P2.5 에서 세 구현을 같은 세션에서 새 방법으로 다시 재서 비교표의 `mem_cpu` 행을 바꾼다 — 0032 의 계획대로.
- 참고(판정 아님): native cold 의 OS 최대가 313 MB 다. 이전 방법의 cold 271~288 MB 보다 높다. SPEC §7.1 의 `mem_cpu` 판정 시나리오는 replay ×60 이다. P2.5 에서 새 방법으로 native·browser 를 다시 판정하고 결과를 그대로 보고한다.
