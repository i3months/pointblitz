# PR #36 검토 노트 — P4.5 1단계: 비용 모델 RTX 4070 보정 + 네트워크별 추정

- 검토일: 2026-10-08
- 대상 커밋: `3a2fd45`
- 결과: **통과(초안)** — P4.5 는 V100 보정 전까지 완료가 아니다. TASKS 완료 표시는 하지 않는다

## 확인

- 단계별 "하드웨어 무관 양 ↔ 하드웨어 값" 짝짓기가 결정 0011·SPEC §6.3 과 맞다. 계수는 같은 세션 실측(P3.4·P4.1)에서 왔고 출처가 적혀 있다.
- 추정표의 수치는 모두 "추정(측정 아님)" 이다. 감독이 네트워크 항을 다시 계산했다(바이트 × 8 / 대역폭 + 루프백 측정에서 전송을 뺀 나머지). three.js refined 1.4 / 6.2 / 28 s, PointBlitz refined 0.35 / 3.2 / 16 s, PointBlitz preview 차분 25–30 ms / 50–90 ms / 0.2–0.4 s 가 맞다.
- "그리기는 메모리 대역폭이 아니라 정점·래스터 처리량이 한계" 라는 판단(29 GB/s ≪ 504 GB/s)은 V100 비교로 확인한다고 적었다 — 좋다.
- 소유자 방침(대역폭·메모리는 제약이 아님)에 따라 LAN·데이터센터를 기본으로 보고 저대역폭은 참고로 둔다고 적었다.
