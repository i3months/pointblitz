## 반려 사유 (높음)

### H1. 위상 잠금의 실패 이유를 실제보다 좋게 썼다 (#10)

- 보고서: "서버 틱을 화면에 맞추는 위상 잠금(끊김을 거의 없애고 지연도 줄였지만 연결 직후 0.7 초의 빠짐 때문에 미리 정한 기준을 두 번 못 맞춤)".
- 실제(결정 0042, server-video.md, PR #44·#45 검토):
  - 두 번 모두 **정밀 스냅샷 지연이 기준(끔 + 2 ms)을 넘었다**. 1 회째는 +11~+38 ms, 2 회째는 +10.6 ms 다.
  - 감독 재현에서는 입력 지연(+12.8 ms)과 늦은 틱도 나빠졌다.
  - 그러니 "지연도 줄였다" 는 입력 → 화면 p50 에만 맞는 말이다(2 회째 작업자 A/B). 실패 이유도 "처음 0.7 초" 하나가 아니다.
- 고칠 것: "빠짐은 줄였지만, 정밀 스냅샷 지연이 늘고(+10.6 ms) 연결 직후 빠짐이 남아 미리 정한 기준을 두 번 못 맞춤" 처럼 두 이유를 함께 쓴다.
