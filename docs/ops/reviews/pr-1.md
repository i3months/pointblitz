## 제안 상태 결정 5건 의견 (소유자 확정용)

- **0006 불투명 + 깊이, 정렬 없음** — 동의. `discard` 비용 측정 조건이 잘 적혀 있다.
- **0008 16 B 청크** — 동의. 법선 포함 시 28 B 로 PLY(27 B)보다 크다는 대가도 맞다.
- **0009 추가 + 세대 교체** — 동의. 근거(비트 동일 100 % / 0 %)를 재현했다. 메모리 계산(2.5 M × 16 B × 2 ≈ 80 MB)도 맞다. H2 문장만 고친다.
- **0013 좌표 규약** — 동의. reversed-Z 를 쓰면 three.js 기준(일반 Z)과 깊이 정밀도가 달라 SSIM 에 작은 차이가 날 수 있으니 P1.3 에서 원인 구분용으로 기록해 두면 좋다.
- **0014 PLY 파서 직접** — 동의. skyrecon `write_ply` 왕복 시험은 skyrecon 을 dev-dependency 로 끌어오게 되므로(라이선스는 호환) 그 방식은 P1.1 에서 정한다.

감독은 이 5건을 승인으로 바꾸지 않았다(PR 본문에 따라 소유자가 확정).
