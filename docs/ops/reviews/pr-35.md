## 결정 (감독, 소유자 위임)

**B 를 한다.** 이유:
- 사용자가 보는 끊김(회전 중 "두 장 + 빈 주기")을 위상과 무관하게 없앤다. P4.3 에서 9 회 중 4 회, 최대 15.23 % 였다.
- 대가는 입력 → 표시·`event_latency` 의 평균 약 +8 ms(최대 한 주기)다. 예상 p50 26~29 ms 로 SPEC §7.1 목표(≤ 50 / 80 ms) 안에 넉넉히 들어간다. INTENT 의 "화질·지연을 바이트·메모리 때문에 희생하지 않는다" 와 부딪히지 않는다 — 여기서는 지연을 조금 써서 매끄러움(화질의 일부)을 얻는다.
- 클라이언트만 바뀌고 서버·전송 형식은 그대로라 되돌리기 쉽다.
